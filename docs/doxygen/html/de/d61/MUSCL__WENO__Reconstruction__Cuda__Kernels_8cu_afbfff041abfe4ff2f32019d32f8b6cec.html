WENO5 reconstruction kernel.

Computes 5th-order accurate WENO reconstruction at cell faces. Uses 5-point stencil with 3 candidate polynomials.

Parameters
U_cellsConservative variables
cell_neighborsNeighbor indices (extended for 5-point stencil)
Q_leftOutput: left reconstructed states
Q_rightOutput: right reconstructed states
num_cellsTotal number of cells
epsilonWENO epsilon parameter (typically 1e-6)
pPower for nonlinear weights (typically 2)

WENO5 reconstruction kernel (corrected)

The left-biased reconstruction at face i+1/2 uses the 5-point stencil {i-2, i-1, i, i+1, i+2} centered on cell i. The right-biased reconstruction at face i+1/2 uses the shifted stencil {i-1, i, i+1, i+2, i+3} centered on cell i+1.

Stencil layout per face: 6 neighbor indices [0]=i-2, [1]=i-1, [2]=i+1, [3]=i+2, [4]=i+3 with cell_idx itself serving as i.
