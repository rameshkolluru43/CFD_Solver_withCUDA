Detailed Description

CUDA implementation of Roe's approximate Riemann solver.

Author
AI Assistant
Date
2026-01-15
Version
1.0

Implements the classical Roe flux scheme with:

  • Roe-averaged states (density-weighted averaging)
  • Eigenvalue/eigenvector decomposition
  • Characteristic variable projection
  • Entropy fix for sonic rarefactions

Reference: Roe, P.L. "Approximate Riemann Solvers, Parameter Vectors, and Difference Schemes" JCP 43, 357-372 (1981)
