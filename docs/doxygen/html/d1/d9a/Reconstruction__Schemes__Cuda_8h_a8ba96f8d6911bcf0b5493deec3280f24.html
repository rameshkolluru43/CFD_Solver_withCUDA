MUSCL reconstruction with slope limiting.

Computes 2nd-order accurate left and right states at cell faces using linear reconstruction with slope limiters.

Q_L = Q_i + 0.5 * phi_L * (Q_i - Q_{i-1}) Q_R = Q_j - 0.5 * phi_R * (Q_{j+1} - Q_j)
